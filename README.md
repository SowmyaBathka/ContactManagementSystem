# Contact Management System

A simple console-based Contact Management System built using Python.

This project allows users to manage contact details efficiently using CRUD operations with persistent JSON storage.

---

## Features

- Add new contacts
- View all saved contacts
- Update existing contacts
- Delete contacts with confirmation
- Search contacts by name or phone number
- Input validation for phone number and email
- Persistent storage using JSON
- Exception handling for safer execution

---

## Technologies Used

- Python 3
- JSON File Storage
- VS Code
- Git & GitHub
